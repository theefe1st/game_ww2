1. [x] Вид карты: гладкая отмывка рельефа, светлая жёлто-зелёная палитра, без деревьев (опция), ж/д (NE railroads) тёмно-серыми,
       точки городов (чёрные) и посёлков (коричневые), подписи цветом владельца, красная линия фронта.
       Фишки дивизий как на эталоне: квадраты СССР (беж., танки оранж., гвардия «Г»), круги Оси (серо-голубые, танки тёмные),

2. [x] Фронты (группы армий): S.fz[r] — фронт области (для владельца), S.fr[side] = [{id,n,col,gen,ord,tgt,auto,man}];

       приказ (авто/оборона/наступление+цель/отход), ручное управление, участок (перекраска областей), создать/расформировать.
       Карта: цветные полосы фронтов вдоль линии (со своей стороны), штабы (кружок с генералом), стрелки наступлений.
3. [x] Экономика: S.mil/S.civ по областям (+вне карты), производственные линии (стрелк., арт., танки, авиация) с
       эффективностью, запасы снаряжения, пополнение из запасов, 🏗 стройка от гражданских фабрик (очередь, предел на проект),
       постройки области: военный завод, гражд. фабрика, укрепления, аэродром, учебный лагерь, склад; эвакуация.
       Учебные лагеря → формирование дивизий в тылу (шаблон, время, снаряжение), ★ политическая власть и решения.
4. [x] Наука: 2–3 слота, ветки (пехота, артиллерия, танки, авиация, промышленность, логистика, доктрины, операции).
       Операции: морской десант (порт → берег через море), воздушный десант (ВДВ с аэродрома), исследования улучшают.

       анимации боёв (вспышки, дым, стрелки) после хода.
