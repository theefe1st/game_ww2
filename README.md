# Мировой фронт

Пошаговая стратегия о Второй мировой войне для Android и браузера: пиксель-арт, исторические операции на гексовых картах, генералы и котлы. Ориентиры — European War, World Conqueror, Unity of Command и Hearts of Iron.

**Текущая версия:** 0.8.0 (versionCode 10) — **«Барбаросса 1941»**, пробная глава новой кампании «Граница: Белосток — Минск, 22–30 июня 1941» за Германию (Гудериан, 2-я танковая группа) или СССР (Голубев, 10-я армия). Это короткие главы: вид и темп первых кампаний, а реализм — в расчётах. На карте 27 × 21 гекс (≈ 20 км) стоят 93 дивизии в составе на 22 июня. Управление — в два касания, с прогнозом боя. Есть очки приказов, способности генералов, исторические решения, «Разведка доносит» и советник штаба, котлы, задачи со звёздами и «Часы Барбароссы». Основная ориентация — альбомная. Решения и итоги версии — в [docs/PLAN-0.8.md](docs/PLAN-0.8.md), всё об игре и дорожная карта — в [дизайн-документе](docs/GDD.md).

Прежние режимы лежат в меню «Архив прототипов»: «Карьера генерала» (Красная армия 1941–1945), «Карта фронта», отдельные операции, «Европа 1939–1945» и штабная карта «Сталинград 1942–1943» (v0.7–0.7.1).

## Как собрать

```bash
npm install
npx vite build --mode single   # один HTML-файл: dist-single/index.html (играть в браузере)
npx vite build                 # dist/ — веб-часть для Android
```

Android (нужны JDK 21 и Android SDK 36, установка — `tools/setup-android.sh`):

```bash
bash tools/unpack-binaries.sh  # иконки, заставка и gradle-wrapper.jar (см. ниже)
npx cap sync android
cd android && ./gradlew assembleRelease
```

Готовый APK: `android/app/build/outputs/apk/release/app-release.apk`. Ключа подписи в репозитории нет: он не должен быть публичным. Без файла `android/keystore.properties` APK собирается неподписанным.

## Что где лежит

| Путь | Что там |
|---|---|
| `src/game.js` | вся игра: правила, ИИ, интерфейс, сценарии (восстановлена из сборки v0.4, имена сокращены) |
| `src/front/` | «Карта фронта»: этапы войны, растеризация, интерактивная карта |
| `src/europe/` | «Европа 1939–1945»: регионы, правила, события, ИИ, карта и интерфейс стратегической кампании |
| `src/ops/` | операции «Харьков 1942» и «Ржев 1942» |
| `src/barb/` | «Барбаросса 1941» (v0.8): гексовая сетка, данные главы «Граница» (состав, генералы, задачи, решения), правила, ИИ и советник, пиксельная графика, карта, интерфейс и стили |
| `src/staff/` | «Сталинград 1942–1943» (v0.7–0.7.1, новая модель): сетка и правила, сценарий «Уран», часовой движок, штабной ИИ, портреты и спрайты, штабная карта, интерфейс и стили |
| `src/data/` | гексовые карты операций (в том числе `map_border41.json` — «Граница»), подложка карты фронта, карта Европы (`europe.json`), карта «Урана» (`uranus42.json`) |
| `tools/` | генераторы карт из Natural Earth, автотесты и симуляции (Playwright + Chromium) |
| `android/` | Android-проект (Capacitor 8) |
| `docs/` | `GDD.md` — дизайн-документ, `CODEMAP.md` — карта кода, `CONCEPT-0.7.md` и `concept-0.7/` — концепция новой модели и макеты (PNG хранятся текстом: `base64 -d docs/concept-0.7/mock1.png.b64 > mock1.png`), `CONCEPT-0.8.md` — исходная концепция v0.8 (вопросы и ответы), `PLAN-*.md` — планы и итоги версий (`PLAN-0.8.md` — «Барбаросса 1941»), `chat-summary.md` — история работы и планы |

## Бинарные файлы

Подключение GitHub, через которое ведётся работа, загружает только текстовые файлы. Поэтому иконки и заставка Android и `gradle-wrapper.jar` хранятся одним текстовым файлом `tools/android-binaries.b64`. Распаковка — `tools/unpack-binaries.sh`, упаковка после изменений — `tools/pack-binaries.sh`.
