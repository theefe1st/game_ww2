# Мировой фронт

Пошаговая стратегия о Второй мировой войне для Android и браузера: пиксель-арт, операции на гексовых картах, режим «Карьера генерала» (Красная армия 1941–1945), «Карта фронта» между операциями, большая стратегическая кампания «Европа 1939–1945» за СССР, Германию или Великобританию и штабная карта «Сталинград 1942–1943». Ориентиры — European War, World Conqueror и Hearts of Iron.

**Текущая версия:** 0.7 (versionCode 8): новый режим «Сталинград 1942–1943: операция «Уран»» — первый срез новой модели. В нём реальный состав сторон (121 соединение, 55 генералов с чертами), дивизии с боеспособностью I–V и директивы армиям. Время идёт по часам, а игрок жмёт «Ход» на сутки. Есть котёл и воздушный мост, играть можно за СССР или за Ось. Что есть в игре, баланс и дорожная карта — в [дизайн-документе](docs/GDD.md), план и итоги версии — в [docs/PLAN-0.7.md](docs/PLAN-0.7.md).

## Как собрать

```bash
npm install
npx vite build --mode single   # один HTML-файл: dist-single/index.html (играть в браузере)
npx vite build                 # dist/ — веб-часть для Android
```

Android (нужны JDK 21 и Android SDK 36, установка — `tools/setup-android.sh`):

```bash
bash tools/unpack-binaries.sh  # иконки, заставка и gradle-wrapper.jar (см. ниже)
npx cap sync android
cd android && ./gradlew assembleRelease
```

Готовый APK: `android/app/build/outputs/apk/release/app-release.apk`. Ключа подписи в репозитории нет: он не должен быть публичным. Без файла `android/keystore.properties` APK собирается неподписанным.

## Что где лежит

| Путь | Что там |
|---|---|
| `src/game.js` | вся игра: правила, ИИ, интерфейс, сценарии (восстановлена из сборки v0.4, имена сокращены) |
| `src/front/` | «Карта фронта»: этапы войны, растеризация, интерактивная карта |
| `src/europe/` | «Европа 1939–1945»: регионы, правила, события, ИИ, карта и интерфейс стратегической кампании |
| `src/ops/` | операции «Харьков 1942» и «Ржев 1942» |
| `src/staff/` | «Сталинград 1942–1943» (v0.7, новая модель): сетка и правила, сценарий «Уран», часовой движок, штабной ИИ, портреты и спрайты, штабная карта, интерфейс и стили |
| `src/data/` | гексовые карты операций, подложка карты фронта, карта Европы (`europe.json`), карта «Урана» (`uranus42.json`) |
| `tools/` | генераторы карт из Natural Earth, автотесты и симуляции (Playwright + Chromium) |
| `android/` | Android-проект (Capacitor 8) |
| `docs/` | `GDD.md` — дизайн-документ, `CODEMAP.md` — карта кода, `CONCEPT-0.7.md` и `concept-0.7/` — концепция новой модели и макеты (PNG хранятся текстом: `base64 -d docs/concept-0.7/mock1.png.b64 > mock1.png`), `PLAN-*.md` — планы версий, `chat-summary.md` — история работы и планы |

## Бинарные файлы

Подключение GitHub, через которое ведётся работа, загружает только текстовые файлы. Поэтому иконки и заставка Android и `gradle-wrapper.jar` хранятся одним текстовым файлом `tools/android-binaries.b64`. Распаковка — `tools/unpack-binaries.sh`, упаковка после изменений — `tools/pack-binaries.sh`.
